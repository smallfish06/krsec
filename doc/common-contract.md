# 공통 API 계약

## 잔고: 제공되지 않는 값과 0원

`Balance.unavailable_fields`는 증권사 응답으로 확인할 수 없는 항목의 JSON 이름입니다. 해당 항목은 JSON 응답에서 제외됩니다. Go 구조체의 숫자는 호환성을 위해 유지되므로, Go 호출자도 이 목록을 확인해야 합니다. 목록에 있는 숫자의 기본값 0은 실제 잔고 0원이 아닙니다.

토스의 보유평가액은 `position_value`, 현금 기준 매수가능금액은 `buying_power`입니다. 이 값으로 예수금·출금가능금액·총자산을 대신하지 않습니다. 증권사 조회 오류가 발생하면 오류를 반환합니다.

LS의 `total_assets`는 `t0424.sunamt` 추정순자산, `position_value`는 `tappamt` 평가금액입니다. 이 응답에 없는 현금·매수가능금액·출금가능금액은 제공되지 않는 항목으로 표시합니다. 추정 D+2 예수금으로 현재 현금을 대신하지 않습니다.

`GET /accounts/summary`는 모든 설정 계좌의 `total_assets`, `cash`, `profit_loss`를 확인할 수 있을 때만 합계를 제공합니다. 계좌 하나라도 조회에 실패하거나 필요한 항목을 제공하지 않으면 HTTP 503과 `ok=false`를 반환하며 일부 계좌의 합계를 정상 결과로 제공하지 않습니다. 실제로 관측한 0원 잔고는 정상 값입니다.

## 소수 수량

소수 주문의 결과에는 정확한 십진 문자열을 사용합니다.

| 응답 | 정확한 수량 필드 |
| --- | --- |
| 주문 결과·상태 | `filled_quantity_decimal`, `remaining_quantity_decimal` |
| 체결내역 | `quantity_decimal` |
| 보유종목 | `quantity_decimal`, `orderable_qty_decimal` |

문자열 필드가 있으면 그 값을 우선합니다. 기존 정수 필드는 호환용이며 소수 부분을 표현하지 못합니다. 0.5주가 체결된 경우에도 체결 행이 유지되고 `quantity_decimal`은 `"0.5"`입니다. 금액 주문처럼 전체 주문수량이 정해지지 않은 경우 남은 수량을 임의로 추정하지 않습니다.

## 연속조회

원본 호출은 한 페이지를 반환합니다. 조회를 계속하려면 다음 페이지 여부와 커서를 함께 전달합니다. 주문 생성·정정·취소에 자동 반복 조회를 적용하지 않습니다.

| 증권사 | HTTP 요청·응답 헤더 | Go 확장 인터페이스 |
| --- | --- | --- |
| 키움 | `cont-yn`, `next-key` | `kiwoom.PageCaller.CallEndpointPage` |
| LS | `tr_cont`, `tr_cont_key` | `ls.PageCaller.CallEndpointPage` |

첫 요청은 연속조회 헤더 없이 보냅니다. 응답의 연속조회 여부가 `Y`이면 응답 커서와 `Y`를 다음 요청에 복사합니다. JSON의 기존 `data` 구조는 유지됩니다. 키움 일반 프록시는 `continuation: {"cont_yn":"Y","next_key":"..."}`도 받습니다. LS는 본문 최상위 `tr_cont`, `tr_cont_key`도 받습니다. 헤더와 본문이 충돌하면 요청을 거절합니다. 프록시 앞에 별도 CORS 계층을 두는 브라우저 앱은 이 응답 헤더를 읽을 수 있도록 노출해야 합니다.

Go에서 생성자로 받은 어댑터를 `kiwoom.PageCaller` 또는 `ls.PageCaller`로 확인한 뒤 사용합니다. 반환되는 `EndpointPage`의 `Data`는 기존 응답 본문이고, `Continuation`은 다음 페이지 정보입니다. 기존 `CallEndpoint` 계약도 유지됩니다.

LS 원본 Go 응답의 JSON 숫자는 큰 주문번호·수량의 정밀도를 보존하기 위해 `json.Number`로 읽습니다. `float64` 직접 타입 단언 대신 `json.Number.String`/`Int64`/`Float64`를 사용합니다. HTTP 응답에서는 계속 JSON 숫자로 반환됩니다.

키움 공통 보유종목·차트, LS 공통 보유종목은 페이지를 순회합니다. 중간 페이지 오류·반복 커서·조회 한도 초과는 오류이며 부분 목록을 정상 반환하지 않습니다. LS의 `cts_*` 본문 커서를 사용하는 TR은 해당 필드도 유지해야 합니다.

## 시장·차트

KIS 국내 주문은 실제 거래소 선택값과 현재 TR을 전송합니다. 모의투자에서 지원하지 않는 거래소는 거절합니다. 키움 공통 시세·차트는 시장에 맞게 NXT `_NX`, SOR `_AL` 종목코드를 만들고 이미 주어진 접미사와 시장이 충돌하면 거절합니다.

KIS 공통 차트는 국내와 해외 가격 API를 구분하고 기간을 역순으로 조회합니다. Go에서 기간·수량을 지정하지 않은 조회는 최근 30개이며 HTTP 기본 수량은 100개입니다. 최대 32페이지를 넘으면 기간 또는 수량 제한을 줄이라는 오류를 반환합니다. 토스 등락은 시세 응답의 거래소 현지 날짜를 기준으로 이전 거래일 종가와 비교합니다. 기준 시각이나 이전 거래일 가격을 확인할 수 없으면 등락을 추정하지 않습니다.

## 지원 범위

LS 공통 주문 관리는 공통 API로 접수한 당일 국내 주문으로 한정됩니다. 주문 문맥은 계좌·실전/모의 환경별 파일에 저장하며 인증키 지문과 주문일을 대조합니다. 조회·정정·취소는 현재 주문 상태를 다시 조회하고, 정정·취소 수량은 확인된 미체결 수량을 넘을 수 없습니다. 원본 API나 다른 프로그램에서 접수한 주문, 다른 거래일 주문, 손상된 문맥은 명시적으로 거절합니다. 정정·취소 접수 성공이 실제 완료를 뜻하지는 않으므로 주문 상태를 조회해야 합니다. 체결조회는 기록된 주문일의 증권사 체결 행을 반환합니다.

원본 REST API 지원은 동일한 기능이 공통 `Broker` 인터페이스에 구현되어 있다는 뜻이 아닙니다. KIS·키움·토스 실시간 WebSocket, 키움 공통 미국주식·분봉은 아직 미지원입니다. LS 실시간 구독은 Go 전용 클라이언트에서 제공합니다. 실시간 명세·기능은 현재 REST drift 검사와 구분해야 합니다.
